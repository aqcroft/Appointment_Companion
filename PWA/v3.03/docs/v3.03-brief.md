# Appointment Companion V3.03 - implementation brief

## Product principle

Appointment Companion must feel like a companion, not an appointment burden.

Default to the ordinary. Pre-empt the exceptional. Reveal extra controls only when the customer or appointment creates a reason for them.

The normal journey should ask only for the minimum information required to produce a trustworthy summary. UW-side information should be automated wherever possible.

## Core UX rules

- Customer setup: name + Homeowner/Tenant are the essential one-time facts. Referral and National League remain optional. Once set, the large essentials panel should collapse into compact editable context.
- Persistent sticky basket/status bar: selected services stay visible at the top, are tappable to jump to their sections, show service progress dots, overall basket progress and running Current vs UW monthly totals.
- Current vs UW is the repeated service comparison language.
- Current and UW are the default two progress requirements. A third exit-fee requirement/dot appears only when Exit fees apply is enabled.
- Optional complexity must not reduce progress until it becomes relevant.
- Preserve V3 architecture and calculations unless explicitly changed below.
- Use 2.42 as the functional UX benchmark where V3 made a simple interaction harder.

## Energy

Normal path:
1. UW / quote usage (secondary label: National database).
2. Current monthly payment.
3. UW Energy price calculated from live tariff data.
4. Fixed tariff selected by default.
5. Exit fees hidden unless enabled.

Alternative controls are progressive:
- Use different usage reveals customer-bill usage or estimate.
- Two separate payments reveals electricity and gas monthly payments.
- Annual bill / advanced current-cost methods stay secondary.
- Peak/off-peak reveals day/night detail and specialist tariffs.

Tariff grid:
- rows = tariff types
- columns = qualifying service count
- applicable service-count column highlighted automatically
- normal profile intended rows: Standard Variable, Tracker, Fixed
- Tracker is supported by the UI but must not invent data if the current feed does not provide it
- EV Variable and Economy 7 rows appear only when Peak/off-peak is enabled
- keep orientation/order consistent with EV Companion
- selected tariff drives the UW running total and final summary
- verify calculated tariff output against equivalent UW website quotes as an acceptance test

## Broadband

- Current monthly total is the primary current input.
- Optional current speed is secondary context.
- Choose connection family first, then speed/package.
- Selecting a UW package populates its UW cost automatically.
- Whole Home Wi-Fi stays as a simple toggle.
- Wording should be "6 months free".
- Remove the normal-flow "manually confirmed UW price" control.
- Exit fee hidden unless enabled.

## Mobile

- Choose number of SIMs.
- Default each SIM to a compact Current vs UW comparison.
- UW plan selection populates UW cost.
- SIM names are hidden by default. "Name SIMs" reveals editable names only when useful.
- Exit fee hidden per SIM unless enabled.

## Boiler Cover

Homeowners only.
- Current monthly cost.
- Known UW monthly cost.
- Exit fee hidden unless enabled.
- Use 🛠️ Boiler Cover.

## Cashback

Restore the proven 2.42-style interaction:
- monthly card-spend slider as the primary control
- average cashback estimate by default
- avoid a technical dropdown as the normal control

Advanced adjustments: leave as-is for V3.03.

## Summary

- Primary button always says "Show Summary".
- Disabled/grey until the required basket information is complete.
- On activation, open at the top of the summary.
- Headline result first.
- Detail sections collapsed by default.
- Preserve Meal Deal, sharing and calculation behaviour.

## Cloud and partner context

- Cloud sync state should be persistent and easy to recognise: synced / syncing-pending / problem.
- Avoid implying data is lost when local storage remains safe.
- Restore useful cloud-conflict inspection before Keep mine / Use Cloud.
- Partner/share identity should be suitable for first-run onboarding. Default role wording: "Authorised Utility Warehouse Partner".
- Major top-left navigation behaviour remains open for later design confirmation and should not be needlessly changed in this pass.

## Preserve

Do not regress:
- calculations and service-count rules
- Welcome Bonus rules
- Meal Deal SIM and shared Meal Deal preview
- local-first storage
- Cloud reconciliation engine
- migration support
- EV Companion
- Should I Fix
- PET
- tariff source-of-truth integration
- activity/history
- basket URLs
- customer-safe sharing

## Safety

Develop only in `PWA/v3.03/` on branch `v3.03-companion-refinement`.

Do not modify 2.42, `PWA/v3/` or `PWA/v3.01/`.

V3.03 must have its own preview database, session keys, Cloud session, specialist-return key and service-worker cache identity.

## Acceptance test

A normal Energy + Broadband + Mobile appointment should be completable by entering little more than the information that genuinely differs from customer to customer:

- name
- Homeowner/Tenant
- service selection
- Energy usage + current payment
- Broadband current payment + UW package
- Mobile current cost + UW plan
- optional exit fees only when they exist
- optional cashback spend adjustment

Then Show Summary.
