# Consolidated v1 reconciliation

This report defines feature parity before any donor control or state path is retired. `/PWA/cloud/` is the definitive feature/UI donor. `/local-first/` is the architectural base. Root `/cloud/` is legacy/reference only and is not an implementation source.

## Feature parity definition

Parity means the consolidated route retains the current PWA Cloud calculation surface, customer controls, basket and savings-card behavior, main share/read-only view, EV, Should I Fix, Earnings, specialist return, and generic/personalised sharing while all customer edits remain usable without Cloud. Direct Cloud-first state writers, duplicate Energy/SIM ownership and unwhitelisted sharing are not parity requirements; they are intentionally replaced.
